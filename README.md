## 🚀 วิธีติดตั้งใช้งาน (สำหรับผู้ไม่ใช่โปรแกรมเมอร์ ทำตามทีละขั้น)

### ขั้นที่ 1 — ขอ Gemini API Key (ฟรี)
1. เข้า https://aistudio.google.com/apikey (ล็อกอินด้วย Google)
2. กด **Create API key** แล้ว **คัดลอกคีย์** เก็บไว้

### ขั้นที่ 2 — อัปโหลดโค้ดขึ้น GitHub
1. สมัคร/ล็อกอิน https://github.com
2. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์โฟลเดอร์นี้ทั้งหมด

### ขั้นที่ 3 — Deploy ขึ้น Vercel (ฟรี)
1. เข้า https://vercel.com ล็อกอินด้วย GitHub
2. กด **Add New → Project** เลือก repository ที่เพิ่งอัปโหลด
3. ไปที่ **Environment Variables** ใส่ค่าต่อไปนี้:

   | ชื่อ (Key) | ค่า (Value) |
   |---|---|
   | `GEMINI_API_KEY` | คีย์จากขั้นที่ 1 |
   | `NEXT_PUBLIC_APP_PASSWORD` | `044357246` |

4. กด **Deploy** รอสักครู่ → ได้ลิงก์เว็บพร้อมใช้งาน 🎉

### ขั้นที่ 4 (ไม่บังคับ) — เปิดระบบบันทึกงานด้วย Supabase
1. เข้า https://supabase.com สร้างโปรเจกต์ใหม่ (ฟรี)
2. ไปที่ **SQL Editor** วางเนื้อหาไฟล์ `supabase-schema.sql` แล้วกด Run
3. ไปที่ **Project Settings → API** คัดลอก **Project URL** และ **anon public key**
4. กลับไปที่ Vercel → Environment Variables เพิ่ม 2 ค่านี้ แล้ว **Redeploy**:

   | ชื่อ (Key) | ค่า (Value) |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public key |

> ถ้าไม่ตั้งค่า Supabase ปุ่ม “บันทึกงาน” จะซ่อนอัตโนมัติ ส่วนอื่นใช้งานได้ปกติ

## 💻 ทดสอบบนเครื่องตัวเอง (ถ้าต้องการ)

```bash
npm install
```

สร้างไฟล์ `.env.local` (ดูตัวอย่างจาก `.env.example`) แล้ว:

```bash
npm run dev
```

เปิด http://localhost:3000
